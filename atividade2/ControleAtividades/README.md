# Controle de Atividades

Este projeto foi desenvolvido para atender a solicitacao do professor Neymar, na materia de Laboratorio de Desenvolvimento Web.

## Briefing da aplicacao

A aplicacao tem como objetivo apoiar o gerenciamento de atividades do dia a dia, permitindo o cadastro, organizacao e acompanhamento de tarefas por categoria.

Principais funcionalidades implementadas:

- Cadastro de atividades com titulo e categoria.
- Listagem de atividades agrupadas por categoria.
- Marcacao de status de conclusao por atividade.
- Edicao de atividades ja cadastradas.
- Remocao individual de atividade (quando concluida).
- Remocao em lote apenas de atividades concluidas.
- Filtro por categoria para facilitar a visualizacao.

## Tecnologias utilizadas

- React
- TypeScript
- Redux Toolkit
- Vite
- CSS

## Como executar o projeto

1. Instale as dependencias:

```bash
npm install
```

2. Execute em ambiente de desenvolvimento:

```bash
npm run dev
```

3. Gere a build de producao:

```bash
npm run build
```
